1. What This Tool Is About (In Short)
When automated tests fail, software engineers usually waste 10 to 15 hours every week reading cryptic logs and opening screenshots.
👉 This tool automatically reads the failure logs and screenshots, tells you the exact root cause in 3 seconds (e.g. Real Bug vs. Changed Button vs. Slow Network), and suggests how to fix the code.

Step-by-Step User Guide
How to Pull, Setup & Use the Tool
Complete instructions for developers, QA testers, and evaluators to run the tool from scratch.
1
How to Pull the Code (Repository URL)

Clone the official project repository from GitHub using Git:

git clone https://github.com/KiranAcad/AI-FEST-ACAD-QA.git cd AI-FEST-ACAD-QA
• Repository: https://github.com/KiranAcad/AI-FEST-ACAD-QA.git • Branch: master
2
Prerequisites & Installation

Install required dependencies for both the copilot backend and Playwright test suite:

# 1. Install project dependencies npm install # 2. (Optional) Ensure Ollama is running locally with coding model ollama pull qwen2.5-coder:1.5b
• Requirements: Node.js >= 18.0.0, Git, and Ollama (for offline local AI inference).
3
How to Start the Project & Dashboard

Launch the web dashboard server with a single npm command:

npm run dashboard

Once started, open your web browser and navigate to: http://localhost:3000

4
How to Use the Tool (Dashboard Features)

The web application at http://localhost:3000 provides 4 core workflow tabs:

📊 Dashboard
High-level executive metrics, category distribution charts & stability trends.
🚨 Failure Triage
Browse triaged failures, view AI explanations, inspect screenshots, and apply code diffs.
🧪 Run Tests
1-click "⚡ Run Tests & Analyze" button. Terminal streams tests and live AI triage!
📑 Reports
Preview or download standalone interactive HTML reports (77 KB), JSON data, or Markdown.
5
Quick CLI Cheat Sheet (For CI/CD & Power Users)
Command What It Does
npm run test:real Executes all 60 Playwright tests across 7 web applications and saves results.json
npm run analyze:ollama Runs AI batch triage from command line using local Ollama model
npm run test:and:analyze:ollama Full end-to-end automated pipeline: executes tests, captures failures, and generates reports
