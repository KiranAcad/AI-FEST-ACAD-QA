1. What This Tool Is About
When automated tests fail in CI/CD pipelines, engineers waste 10 to 15 hours every week reading cryptic stack traces, downloading failure screenshots, and trying to decipher why the test broke.
👉 This tool automatically digests the error logs and screenshots, classifies the exact root cause in ~3.4 seconds (e.g. Real Bug vs Broken Selector vs Network Timeout), and generates unified git diffs to repair test scripts on disk.

🖥️ Headed Live Browser Mode
Click "🖥️ Run Headed (Live Preview)" in the dashboard to launch a visible Chromium browser window. Watch tests navigate, fill forms, and click elements in real time.
📹 In-Dashboard Video Replay
Playwright automatically records high-definition .webm videos of test runs. Review browser actions leading up to any failure directly in the embedded dashboard player.
⚡ Live SSE Terminal Streaming
Test execution stdout/stderr streams to the web console via Server-Sent Events (SSE) with live status indicators (● Running, ● Idle) and no browser refreshes.
🛠️ 1-Click Self-Healing Git Diffs
For broken locators and timeouts, the copilot generates verified unified git diffs that can be applied to test spec files on disk with a single click and automatic safe backups.

7. Step-by-Step User Guide (How to Pull, Setup & Use)
1
Clone Repository & Install Dependencies
git clone https://github.com/KiranAcad/AI-FEST-ACAD-QA.git cd AI-FEST-ACAD-QA npm install
• Prerequisites: Node.js >= 18.0.0, Git, and Ollama (for offline local AI inference).
2
Launch the Interactive Web Dashboard
npm run dashboard

Open your browser and navigate to: http://localhost:3000

3
Run Tests & Watch Live Execution (UI Features)

Navigate to 🧪 Run Tests in the sidebar. Choose your execution mode:

🖥️ Run Headed
Opens visible Chromium window to watch the robot click live.
⚡ 1-Click Run
Runs tests and immediately streams AI root cause triage cards.
📹 Video Replay
Watch recorded .webm videos of user actions and failures.
🚨 Failure Triage
Inspect screenshots, root cause, and 1-click self-healing diffs.
Command What It Does
npm run dashboard Starts the web dashboard on http://localhost:3000
npm run test:real Executes all 60 Playwright tests and generates results.json + videos
npm run analyze:ollama Runs AI batch triage from command line using local Ollama model
npm run test:and:analyze:ollama End-to-end pipeline: executes tests, captures failures, and streams AI triage
